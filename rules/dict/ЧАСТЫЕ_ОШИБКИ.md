# ЧАСТЫЕ ОШИБКИ ПРИ РАСЧЁТЕ ХАРАКТЕРИСТИК WFRP 4e

Этот документ содержит список самых распространённых ошибок при создании и проверке персонажей.

---

## ❌ ОШИБКА 1: Талант "Закалка" увеличивает характеристику В

### Неправильно:
```
В (Выносливость) = 38 + 5 (Закалка) = 43 ❌
HP = 13
```

### Правильно:
```
В (Выносливость) = 38 ✅
HP = 13 + 5 (Закалка) = 18 ✅
```

### Объяснение:
**Закалка (Toughened)** увеличивает **HP (Раны)**, а НЕ характеристику Выносливость!

Текст правил ("Начальное значение выносливости") - это неточный перевод. Имеется в виду **здоровье (HP)**.

---

## ❌ ОШИБКА 2: Бонусный опыт используется для покупки характеристик

### Неправильно:
```
С = 36 + 4 шага развития за 100 опыта = 40 ❌
```

### Правильно:
```
С = 36 (базовая) ✅
Опыт = 100 (бонус за случайные броски без перестановок)
```

### Объяснение:
**100 опыта** за случайные броски без перестановок - это **бонусный опыт**, который нельзя потратить при создании персонажа!

При создании можно распределить только **5 шагов развития между 3 характеристиками карьеры** (отмечены ¢ в схеме развития).

**ВАЖНО: Два источника опыта!**

При создании персонажа можно получить опыт из **двух независимых источников**:

**1. Опыт за генерацию характеристик** (стр. 1055-1080):
- Способ 1 (броски без перестановок): **+50 опыта**
- Способ 2 (броски с перестановками): **+25 опыта**
- Способ 3 (ручное распределение): **0 опыта**

**2. Опыт за выбор класса/карьеры** (стр. 942-1027):
- Способ 1 (первый бросок подошёл): **+50 опыта**
- Способ 2 (выбор из 3 бросков): **+25 опыта**
- Способ 3 (ручной выбор): **0 опыта**

**Максимум = 100 опыта** (50 + 50)

**ВСЕГДА** спрашивай игрока, каким способом он генерировал характеристики И карьеру!

## ❌ ОШИБКА 3: Дублирующиеся навыки - это плохо

### Неправильно:
```
Выживание есть и у расы, и у карьеры - надо выбрать что-то другое ❌
```

### Правильно:
```
Выживание: Инт 42 + 5 (раса) + 5 (карьера) = 52 ✅
```

### Объяснение:
**Дублирование навыков - это ХОРОШО!** Шаги развития **СУММИРУЮТСЯ**.

Это делает персонажа сильнее в этом навыке, без штрафов или ограничений.

## ❌ ОШИБКА 4: Неправильный статус для карьеры

### Неправильно:
```
Зверолов (Ранг 1) - Бронза 3 ❌
```

### Правильно:
```
Зверолов (Ранг 1) - Медный 2 ✅
```

### Объяснение:
Статус указан **в схеме развития карьеры** рядом с названием ранга.

Проверяй в правилах (глава 3: Классы и карьеры).

## ❌ ОШИБКА 5: Завышенное начальное богатство

### Неправильно:
```
Медный 2 - начинаю с 12 золотыми кронами ❌
```

### Правильно:
```
Медный 2: 2d10 мп × 2 = 4d10 мп (~22 мп среднее) ✅
```

### Объяснение:
**Начальное богатство** рассчитывается по формуле:
- **Медное сословие:** 2d10 мп × уровень
- **Серебряное сословие:** 1d10 сш × уровень
- **Золотое сословие:** 1 зк × уровень

**НЕ завышай** деньги у начинающих персонажей!

## ❌ ОШИБКА 6: Неправильная карьера для персонажа

### Неправильно:
```
Карточка: Охотник (Ранг 1)
Навыки: от Зверолова
Таланты: от Зверолова
Снаряжение: от Зверолова
❌ Несоответствие!
```

### Правильно:
```
Если навыки, таланты и снаряжение от Зверолова,
то карьера = Зверолов (Ранг 1) ✅
```

### Объяснение:
**Всегда проверяй соответствие:**
1. Название карьеры
2. Ранг карьеры
3. Навыки карьеры
4. Таланты карьеры
5. Снаряжение карьеры
6. Статус карьеры

Всё должно быть с **одного ранга** одной карьеры!

## ❌ ОШИБКА 7: Формат характеристик без полных названий

### Неправильно:
```
ББ = 48, С = 36, В = 38 ❌
```

### Правильно:
```
ББ (Ближний бой) = 48
С (Сила) = 36
В (Выносливость) = 38
✅
```

### Объяснение:
**ВСЕГДА** указывай полное название рядом с сокращением для ясности.

## ❌ ОШИБКА 8: Неправильное применение психического состояния "Ужас"

### Неправильно:
```
Состояние "Ужас" даёт -10 ко всем проверкам, если персонаж испуган ❌
```

### Правильно:
```
Состояние "Ужас" (Terror) применяется ТОЛЬКО при виде существа с качеством "Ужасное" (Fear)
или в специфических ситуациях, описанных в правилах. Обычный страх не даёт штрафов.
```

### Объяснение:
**Психическое состояние "Ужас"** — это конкретное механика, а не общий штраф за страх:
- Активируется при встрече с существом, имеющим качество **"Ужасное" (Fear)**
- Требует проверки **Силы воли** против указанного уровня Ужаса
- При провале даёт состояние "Ужас" с конкретными штрафами (обычно -10 к определённым проверкам)
- **Обычная стрессовая ситуация не даёт автоматически состояния "Ужас"**

**Проверяй в правилах:** `rules/dict/ПСИХОЛОГИЯ_СОСТОЯНИЯ.md` для точных условий.

## ❌ ОШИБКА 9: Забывают учитывать таланты персонажа при проверках

### Неправильно:
```
Наблюдательность: 62
Модификаторы: -10 (темнота)
Целевое число: 52 ❌
```

### Правильно:
```
Наблюдательность: 62
Талант "Обострённое зрение" (эльфы): +20
Модификаторы: -10 (темнота)
Целевое число: 72 ✅
```

### Объяснение:
**ВСЕГДА проверяй таланты персонажа перед объявлением проверки!**

Таланты могут:
- **Добавлять бонусы к навыкам** (например, +10, +20 к определённым проверкам)
- **Давать новые возможности** (например, видеть в темноте, игнорировать штрафы)
- **Изменять условия проверки** (например, переводя сложную проверку в заурядную)

**Частые таланты, которые легко забыть:**
- **"Обострённое зрение" (эльфы):** +20 к Наблюдательности, частичное игнорирование штрафов тёмности
- **"Закалка":** не влияет на В, влияет на HP!
- **"Боевая подготовка":** +5 к боевому осознанию и инициативе
- **"Чувство опасности":** +10 к проверкам избегания ловушек
- **"Ночное зрение":** видение в полной тьме (дварфы)

**КРИТИЧЕСКОЕ ПРАВИЛО:** Перед объявлением целевого числа ВСЕГДА:
1. Открой карточку персонажа
2. Прочитай список всех его талантов
3. Отметь те, что применяются к данной проверке
4. Добавь их бонусы к расчёту

## ❌ ОШИБКА 10: Неправильная терминология для проверок и характеристик

### Неправильно:
```
Проверка: (ИГ 30) — Интуиция
Проверка: (ЛВ 35) — Ловкость
Описание: "Видит с помощью (ИГ) Интуиции"
❌ Придуманные сокращения!
```

### Правильно:
```
Проверка: Интуиция (30) — если базовое значение 30
Проверка: Ловкость (35) — если базовое значение 35
Описание: "Видит с помощью Интуиции (И)"
✅ Используй официальные сокращения!
```

### Объяснение:
**ВСЕГДА используй официальные сокращения из правил:**
- **С** = Сила
- **В** = Выносливость
- **И** = Инициатива
- **Пр** = Проворство
- **Л** = Ловкость
- **Инт** = Интеллект
- **СВ** = Сила воли
- **Х** = Харизма

**Формат записи проверок:**
- Навык (целевое число): "Наблюдательность (45)"
- При модификаторах: "Наблюдательность (45 – 10 за темноту = целевое число 35)"

**НЕ ПРИДУМЫВАЙ** собственные аббревиатуры типа (ИГ), (ЛВ) и т.д.!

## ❌ ОШИБКА 11: Неверные цены при торговле

### Неправильно:
```
Кольчужная рубаха = 75 сш ❌
Кольчуга полная = 150 сш ❌
```

### Правильно:
```
Кольчужная рубаха = 2 зк (40 сш) ✅
Кольчуга полная = 3 зк (60 сш) ✅
```

### Объяснение:
**ВСЕГДА сверяй цены со справочниками:**
- **`04_навыки_и_таланты.md`** — таблицы с ценами на оружие и броню
- **`ЭКОНОМИКА.md`** — таблицы с ценами на товары и услуги

**НЕ используй "примерные" или "придуманные" значения!**

Правила WFRP 4E содержат точные цены на всё:
- Мягкая кожа: Кожаная жилетка 10 сш, Кожаная куртка 12 сш
- Варёная кожа: Кожаная кираса 18 сш
- Кольчуги: Кольчужная рубаха 2 зк, Кольчуга полная 3 зк
- Латы: Латная кираса 10 зк, Шлемы 2-3 зк

**КРИТИЧЕСКОЕ ПРАВИЛО:** При объявлении цены товара ВСЕГДА:
1. Проверь цену в `04_навыки_и_таланты.md` (оружие/броня)
2. Или проверь цену в `ЭКОНОМИКА.md` (товары/услуги)
3. Используй ТОЛЬКО официальные значения

## ✅ КОНТРОЛЬНЫЙ СПИСОК ПРИ ПРОВЕРКЕ ПЕРСОНАЖА

### Характеристики:
- [ ] Базовые значения соответствуют расе
- [ ] HP рассчитаны правильно (формула для расы)
- [ ] Закалка влияет только на HP, не на В
- [ ] Движение соответствует расе
- [ ] Формат записи: "ББ (Ближний бой) = 48"

### Навыки:
- [ ] От расы: 3 навыка ×5 шагов + 3 навыка ×3 шага
- [ ] От карьеры: правильное количество навыков для ранга
- [ ] Дублирующиеся навыки суммированы правильно
- [ ] Итоговые значения = База + Шаги развития

### Таланты:
- [ ] От расы: все обязательные таланты выбраны
- [ ] От карьеры: соответствуют текущему рангу
- [ ] Дублирующиеся таланты отмечены как уровень 2

### Карьера:
- [ ] Название карьеры соответствует рангу
- [ ] Статус соответствует рангу карьеры
- [ ] Снаряжение соответствует рангу карьеры
- [ ] Богатство рассчитано по статусу

### Опыт:
- [ ] Начальный опыт указан (0, 25, 50 или 100)
- [ ] Не потрачен на характеристики при создании

### Товары и услуги:
- [ ] Цены проверены в `04_навыки_и_таланты.md` или `ЭКОНОМИКА.md`
- [ ] Не используются "примерные" или "придуманные" цены

## 🔧 БЫСТРЫЕ ФОРМУЛЫ

### HP (Здоровье):
- **Человек, Эльф, Дварф:** Бонус С + (2 × Бонус В) + Бонус СВ
- **Полурослик:** (2 × Бонус В) + Бонус СВ

### Движение:
- **Человек:** 4
- **Дварф:** 3
- **Полурослик:** 3
- **Эльф:** 5

### Начальное богатство:
- **Медное X:** 2d10 мп × X
- **Серебряное X:** 1d10 сш × X
- **Золотое X:** 1 зк × X
