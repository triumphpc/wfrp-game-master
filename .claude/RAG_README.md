# WFRP RAG - Поиск правил

## Установка (выполнено)

- Зависимости установлены: `sentence-transformers`, `numpy`
- Индекс создан: `1448 секций` из `wfrp-repo/rules/`

## Использование

### Командная строка:
```bash
wfrp-repo/.claude/wfrp-rules "проверка навыка успех"
wfrp-repo/.claude/wfrp-rules "бросок атаки урон"
wfrp-repo/.claude/wfrp-rules "карьера охотник"
```

### Как инструмент OpenClaw:
```
tool: exec
command: wfrp-repo/.claude/wfrp-rules "ваш запрос"
```

## Примеры запросов

- "проверка характеристики навыка успех провал"
- "рукопашный бой атака урон заминка"
- "карьера охранник требования продвижение"
- "получение опыта развитие персонажа"
- "магия заклинания концентрация денарий"

## Интеграция с GM

Добавь в промпт GM:

```
ИНСТРУКЦИИ ПО ИСПОЛЬЗОВАНИЮ ПРАВИЛ:

1. Перед любой проверкой - найди точные правила через RAG
2. Всегда цитируй источник (файл и страницу)
3. При спорных ситуациях - ищи в dict/ПРОВЕРКИ.md и dict/БОЙ.md
4. Не придумывай механики - используй только найденные правила

Поиск правил: wfrp-repo/.claude/wfrp-rules "запрос"
```

## Переиндексация

Если добавили новые правила:
```bash
python3 wfrp-repo/.claude/rag_indexer.py index
```
