## 📐 РАСЧЁТ ЛИМИТА ОБРЕМЕНЕНИЯ

**Формула:**
```
Лимит = РС + РВ
```

**Пример:**
- Сила (С) = 32 → РС = 3
- Стойкость (В) = 59 → РВ = 5
- **Лимит = 3 + 5 = 8 единиц**
