# Рендер карточки персонажа в PNG

## Когда запускать
- Игрок/мастер просит показать карточку: «покажи карточку Феликса», «card Гюнтер», «карточка партии».
- Нужно прислать карточку в Telegram-чат красиво (а не markdown'ом).

## Доступные темы

| Тема | Когда использовать | Ключевые слова в запросе |
|------|--------------------|--------------------------|
| `parchment` *(default)* | Универсальная: люди, базовая | «обычная», «классика», по умолчанию |
| `sylvan` | Эльфы (особенно лесные), охотники, рейнджеры | «эльф», «эльфийская», «лесная», «охотник» |
| `dwarven-rune` | Гномы, дварфы | «гном», «дварф», «гномья», «руническая», «каменная» |

**Эвристика выбора темы:** определяй автоматически по расе/карьере персонажа из MD-карточки:
- Раса = лесной/эльф → `sylvan`
- Раса = гном/дварф → `dwarven-rune`
- Иначе → `parchment`

Игрок может явно перебить тему: «карточку Феликса в гномьем стиле» → `dwarven-rune`.

## Шаги выполнения

### 1. Найти карточку
Карточки лежат в:
- `./history/<campaign_name>/characters/character_*.md` — текущая кампания (приоритет)
- `./characters/character_*.md` — общие/архивные

### 2. Запустить рендер

```bash
python3 .claude/skills/render-character-card/render.py "<md_path>" [--theme <theme>] [--out <png>]
```

**Примеры:**

```bash
# По умолчанию (parchment), PNG рядом с MD
python3 .claude/skills/render-character-card/render.py \
  "./history/Тени Старого Тракта/characters/character_feliron.md"

# Явная тема
python3 .claude/skills/render-character-card/render.py \
  "./history/Тени Старого Тракта/characters/character_feliron.md" \
  --theme sylvan

# Кастомный путь вывода
python3 .claude/skills/render-character-card/render.py \
  "./history/Тени Старого Тракта/characters/character_trongold.md" \
  --theme dwarven-rune --out /tmp/trongold.png
```

### 3. Куда сохраняется PNG
- Тема `parchment` → `<md_basename>.png` (рядом с MD)
- Другие темы → `<md_basename>_<theme>.png` (чтобы не перезаписывать дефолт)

### 4. Отдать в чат
Отправь полученный PNG в чат как изображение. Если нет возможности — сообщи путь.

```bash
pip install markdown jinja2 playwright

```

## Особые случаи

- **Карточка партии (`party_summary.md`)** — рендерится `parchment` темой; универсально.
- **Несколько персонажей разом** — вызывай скрипт по одному на персонажа, тема выбирается под каждого индивидуально.
- **PNG уже существует и MD не менялся** — можно переиспользовать без рендера. Проверка: `mtime(png) > mtime(md)`.

## Чего НЕ делать
- Не пытайся рендерить вручную через PIL/ASCII.
- Не запускай рендер ради каждого мелкого изменения — только когда явно просят показать карточку или после крупного апдейта (новый XP, смена карьеры, после сессии).
- Не правь шаблон/CSS под одного персонажа — темы универсальны для всей расы/типа.

## Добавление новой темы

1. Создай `.claude/skills/render-character-card/themes/<name>.css`
2. Используй `themes/parchment.css` как референс (структура селекторов).
3. Обнови этот SKILL.md — добавь строку в таблицу тем + эвристику выбора.
